# Steam tags

Steam lets a developer apply up to 20 tags; the first ones carry the most weight on the store page and in recommendations. Suggested order:

1. Horror
2. Psychological Horror
3. Survival Horror
4. First-Person
5. Atmospheric
6. Short
7. Story Rich
8. Exploration
9. Supernatural
10. Singleplayer
11. Dark
12. Mystery
13. 1990's
14. Retro
15. Realistic
16. Puzzle
17. Investigation
18. Thriller
19. Indie
20. Linear

Left out on purpose: **Walking Simulator** (there are hunts and a fail state, so it sets the wrong expectation) and **Jump Scare** (true, but it tends to attract reviews that complain about cheap scares).

## Genre and category settings in Steamworks

- Genres: Adventure, Indie.
- Categories: Single-player, Steam Achievements (only if they are added), Full controller support (only if tested), Steam Cloud (only if saves are hooked up).

## Similar games to name when Steam asks ("More like this")

Short first-person horror with one location and a slow build: *Visage*, *MADiSON*, *Fears to Fathom*, *The Mortuary Assistant*, *Paratopic*. These are for Steam's positioning only; don't name them on the store page.
